## Pictures in panes

### Fixed
- A pane now says it draws on keepane: `TERM_PROGRAM=keepane`, `TERM_PROGRAM_VERSION` and `COLORTERM=truecolor` (as tmux says `TERM_PROGRAM=tmux`). The names of the terminal the server was started from are taken away in a pane (`WT_SESSION`, `WT_PROFILE_ID`, `KITTY_WINDOW_ID`, `KITTY_PID`, `ITERM_SESSION_ID`, `LC_TERMINAL`, `LC_TERMINAL_VERSION`). Before, a server started from UnifyTerm or Windows Terminal passed those on, so `ut view` in a pane sent kitty or sixel pictures that keepane does not show, and the pane stayed blank; now it draws half blocks. A `set-environment` of any of these names still wins, and `prefix e` lists them.

### Changed
- Releases now carry these notes, written by hand for each version (`docs/releases/vX.md`), not only a compare link.
