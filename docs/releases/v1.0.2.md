## Keys go to another machine as typed

### Changed
- Keys typed into a pane of another machine now go across as the keys themselves, and the machine the pane runs on turns them into what its program reads, by its own system and the pane's current modes. In 1.0.1 the machine you typed on did this for the other machine. With `synchronize-panes`, each pane now gets keys by its own modes (an arrow key reaches vim in one pane and a shell in another correctly).

### Breaking: both machines need 1.0.2 to type into each other's panes
- Typing into a pane of a machine that runs an older keepane does nothing, and the status line says once per connection which machine to update. Update both machines to 1.0.2. Watching, copying and everything else between machines still works with older versions.

### Fixed
- On Windows, pressing Enter in a pane is now seen as sending the line. Before, keepane took the pane as still being typed into until the next prompt appeared. Shift+Enter is a line break and does not count as sending.
