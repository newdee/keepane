## Group files

Every file sent in a channel is now one of its **group files**, kept until it is deleted (no longer pruned by `chat-days`).

### New
- `keepane chat group-files CHAN [-J]` lists a channel's group files, newest first: name, size, who sent it, its line, its day, and where to open it. `keepane chat group-file-rm CHAN FILE` deletes one (the pane that sent it, or you). MCP tool `chat_group_files`.
- A member on another machine gets each file's **link** instead of a path it cannot open: a share with no end, listed by `keepane share` as "for group file #chan #N", stopped when the file is deleted.
- **Dashboard**: the chat page's `[0]` is now `[0] Group files`. The file under the cursor shows in `[4]` (pictures and markdown through UnifyTerm's `ut` when it is installed; without it, a picture says so); another machine's file is fetched by its link first. `Enter` scrolls it, `y` copies its path or link, `d` deletes it after a yes.
- **Web page**: the 📎 button over a channel opens its group files, to see, save or delete. A file in a line now opens a preview (save from there). A new **shares view** (🔗 in the header on a wide screen, the Appearance menu on a phone) lists what this machine shares: see a file, copy the link, make it end 1 h / 24 h / 7 d from now or never, or stop it after a yes. A read-only page only looks.
- Previews are judged by a file's first bytes, not its name: PNG, JPEG, GIF, WebP and PDF up to 50 MiB, UTF-8 text its first 256 KiB. An SVG or a web page is shown as text, never drawn or run.

### Changed
- On the web page, tapping a file in a line opens its preview instead of saving it at once.
