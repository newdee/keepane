## keepane 1.0

### What 1.0 means
- From 1.0, the version number tells you what an upgrade can do. 1.x.y → 1.x.(y+1) brings fixes only. 1.x → 1.(x+1) adds things, and nothing that worked stops working. Only 2.0 may take something away or change what it means. [docs/compatibility.md](https://github.com/newdee/keepane/blob/master/docs/compatibility.md) lists what stays the same through 1.x: commands and their flags, options, `#{…}` formats, default keys, MCP tools, `-J` and event-log JSON, files, `KEEPANE_*` variables, and links between machines.
- Your own files are covered too: the settings file, your themes (`NAME.conf` in `theme-path`, with their `@` tokens), and agent definitions (`~/.keepane/agents/*.toml`). Every 1.x reads what an earlier 1.x wrote.
- The group chat (`chat-*`, its MCP tools, its group files) is still experimental and may change in a 1.x.

### New
- `set -g remain-on-exit failed` keeps a pane only when its program ended with an error (an exit code other than 0). The pane shows the program's output and its exit code, so a mistyped `new-window` command or a crash at start is no longer gone before you can read it. A program that ends well still closes its pane. `on` and `off` work as before. In the settings board this option is now a choice (←/→), and a wrong value names all three values.

### Fixed
- Forgetting a session (`delete-saved`, or `D` in choose-tree) now also removes the earlier save kept beside it (`.json.prev`). Before, `resume --prev` could still bring back a session you had told keepane to forget.

### Changed
- Code moved to the modules it belongs to. Nothing you can see changed.
