## Typing into another machine's pane

### Fixed
- Keys typed into a pane of another machine now reach its program. Before, typing from Windows into a Mac's or a Linux machine's pane printed codes such as `6;38;108;1;0;1_` instead of the letters, so no command could be typed. Keys are now encoded for the machine the pane runs on: win32-input-mode for Windows, so Shift+Enter and every modifier arrive as typed, and xterm keys for macOS and Linux. Only the machine you type on needs 1.0.1. When the other machine runs an older keepane, its panes get xterm keys, which every system reads.
